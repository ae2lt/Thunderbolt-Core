# 合成冲突核、Missing 路线选择与预算搜索设计

## 文档状态

- 状态：设计草案，尚未实现。
- 适用模块：`CraftPlannerV2`、`FastCraftingPlanner` 及其诊断输出。
- 本文只定义规划和诊断语义，不改变 AE2 的合成执行语义。

## 目标

1. 普通 Minecraft 合成图继续走数量无关的聚合传播，不按合成份数展开。
2. 只把真正受共享库存约束的局部分量视为冲突核。
3. 始终尽快产生一份完整、质量守恒、Missing 已传导到原料叶子的具体计划。
4. 搜索预算耗尽时返回当前路线选择策略下最好的 concrete candidate，而不是卡住或退回截断的中间物品 Missing。
5. 没有可行解时，按照真正发生竞争的共享资源选择一条具体路线，再展示该路线传导完成后的 Missing。
6. 互斥路线的 Missing 不得合并成一份并不存在的缺失清单。
7. 启发式只调整搜索优先级；没有严格证明时不得硬剪枝。
8. 所有求解路径只由图结构、库存约束和整数系数触发，不识别物品名、层级名或某一种测试图形。

## 非目标

- 不维护整个合成图的全局 Pareto 前沿。
- 不枚举 `0..Q` 的合成量或路线分配量。
- 不保证一般情况下的全局最少 Missing。
- 不维护或展示互斥路线的 Pareto 候选集。
- 不保证预算耗尽时返回的候选已经被证明为全局最优。
- 不把“活跃资源不超过 30 种”写成正确性假设；它只能作为快速路径的领域假设。
- 不增加 `isFibonacci`、配方名称匹配、固定层数或固定递推式等生产特判；Fib 只是一类压力测试。

## 术语

### Concrete candidate

一份完整的、可以回放的规划结果，包括：

- 每个样板的执行次数；
- 实际使用的库存；
- 副产物、容器和可复用输入的流转；
- 完整传导到不可合成原料叶子的 Missing。

不同候选的 Missing 只有在使用相同的叶子规范、计量单位和模糊物品归一化规则后才能比较。

### 支配

对于两个 Missing 向量 `A` 和 `B`，不存在的键按 `0` 处理。若：

```text
对所有原料 k：A[k] <= B[k]
并且至少存在一个 k：A[k] < B[k]
```

则称 `A` 严格支配 `B`。

该关系只在两份完整候选已经传导到相同的规范化叶子，并且库存作用域、副产物、容器、模糊替代和可复用输入语义全部可比时成立。条件不足时不能仅根据局部缺口声称支配，也不能据此硬剪枝。

完整支配仍可作为条件充分时的证明工具，但不作为 AE2 Missing 展示路线的主要选择规则。

### 竞争资源投影

对同一产物的互斥路线，只把会在路线之间争用、且库存可能不足的共享资源放入路线选择分数。路线私有原料只用于计算该路线的库存容量、可行性和最终 Missing，不加入这一步的 Pareto 维度。

例如两条路线分别使用私有原料 `A`、`B`，但共同争用 `C`，则路线由 `C` 的单位消耗或缺口决定；选择完成后才沿对应的 `A` 或 `B` 子图继续传导 Missing。

“私有”必须在确定性下游完全收缩后判定，不能按某条样板的直接输入判定。若两个表面独立的输入会在更低层重新汇合、属于同一模糊库存组、共享副产物或复用库存，或者仍连接同一个未消元决策，它们都必须留在冲突分量的活动边界中。

### Incumbent

搜索期间当前保留、最终可以直接交给 AE2 展示的 concrete candidate。可行候选始终优先于任何 Missing 非空的候选；没有可行候选时，按照竞争资源投影和稳定次序选择 incumbent。

### 冲突核

经过确定性子图收缩、等价路线合并、证明成立的严格支配路线删除以及非活跃资源投影后，仍然包含整数路线分配选择的局部分量。

## Minecraft 领域假设

真实整合包通常具有以下结构：

- 大部分产物只有一个有效样板；
- 样板输入少、系数小，依赖大多局部；
- 很多多样板路线展开到原料边界后等价、严格更优或严格更劣；
- 真正共享稀缺库存的分量通常很小；
- 即使表面竞争节点很多，有效差分秩和消元边界宽度通常很低；
- 超过约 30 种活跃冲突资源的高维实例更可能是刻意构造，而不是自然形成。

该假设用于决定快速路径和预算，不用于宣称通用多项式复杂度。

## 总体流程

### 1. 确定性聚合传播

沿用当前 `linearPass` 的闭式批量计算：

- 使用 `ceilDiv` 计算样板执行次数；
- 聚合同一物品的全部需求后只处理一次；
- 先使用库存和已经产生的副产物；
- 传播到原料叶子；
- 立即得到第一份 concrete candidate，并设为 incumbent。

合成数量 `Q` 只作为整数系数参与运算，不能成为循环次数。

### 2. 收缩确定性子图

对每条竞争路线，把没有选择的下游区域收缩成稀疏的净资源摘要：

```text
路线分配量 -> 边界资源消耗、保证副产物、余数和一般可复用输入需求
```

收缩时必须保留：

- 样板批量和向上取整；
- 多输出和副产物；
- 容器余数；
- 模糊输入的共享库存组；
- 普通容器返还和一般催化剂；
- 一般配方环的已切方向和启动库存下界。

AE2LT 的 host-scoped reusable stock、闭环种子池和状态转换不进入本通用摘要；它们由 AE2LT 的闭环 Planner SPI 实现处理。

只有输出量已经归一化、边界语义相同的路线才能做向量比较。

收缩同时为每个边界资源维护饱和所有者标记：`none`、`single(componentId)` 或 `shared`。不同决策分量的所有者在确定性下游相遇时直接升级为 `shared`，不保存完整来源集合，也不计算传递闭包。一个资源只有保持 `single`，且没有共享库存或副作用耦合时，才能降为路线私有容量。该标记在逆拓扑边扫描中传播，总成本为 `O(V+E)`。

### 3. 删除无效的表面竞争

依次执行：

1. 合并净资源向量完全相同的路线。
2. 仅当私有输入、全部输出和其他副作用也已经完整归一化并可比较时，删除被严格支配的路线。
3. 仅在收缩后的所有者标记仍为 `single` 时，删除与其他选择不共享任何约束资源的独立边。
4. 通过库存上下界判断资源是否真的可能形成冲突。

对资源 `k` 定义：

```text
L[k] = 所有路线选择下都至少需要的数量
U[k] = 某种路线选择下最多可能需要的数量
S[k] = 进入冲突核时可分配的库存和保证供给
```

分类规则：

```text
U[k] <= S[k]       永远不会卡住，不进入冲突维度
L[k] > S[k]        存在不可避免的缺失下界
L[k] <= S[k] < U[k] 真正的活跃冲突资源
```

### 4. 构造局部冲突分量

构造二部图：

```text
整数路线分配变量 <-> 活跃共享资源
```

不连通分量可以独立规划。需要记录三个不同指标：

- `activeResources`：活跃资源种类数；
- `differenceRank`：路线净消耗差向量的独立方向数；
- `separatorWidth`：变量消元时最大的活动边界宽度。

表面竞争节点数不能单独代表求解难度。

## 通用低分离宽度局部求解

低宽度求解器面向任意局部冲突分量，不识别具体递推式。它复用已有逆拓扑顺序，并以边界资源的未处理引用数维护消元前沿：

1. 取下一个路线分配变量，聚合它对输入、输出、库存和余数的整数约束。
2. 只把同时连接“已处理决策”和“未处理决策”的资源留在活动边界。
3. 对活动边界保存稀疏的整数区间、仿射关系和必要的 `gcd`/同余信息。
4. 只在通用语义产生的断点处分裂：库存耗尽、路线容量、样板批量向上取整、区间端点以及合法余数变化。
5. 边界键、仿射关系和同余类相同的状态，只有在区间并集可被精确表示时才合并。
6. 分量消元完成后回放保存的父指针，得到一套具体路线分配，再按正常流程生成计划或叶子 Missing。

活动边界可以在一次边扫描中维护。除现有拓扑排序外，普通确定性 DAG 只增加 `O(V+E)` 的引用计数和分量标记，不进入局部状态求解。是否使用宽度受限路径只取决于测得的 `separatorWidth` 和符号状态片段预算，与物品名和测试图形无关。

生产路径不计算最优树宽，也不运行 `min-fill`、递推式识别或图同构。直接使用现有稳定逆拓扑序测量一个可复现的 separator-width 上界；宽度足够小就进入通用局部求解，宽度过大就保留预算搜索。这样不会为了改善某个测试形状而提高普通图的渐近预处理复杂度。

设分量 `i` 的边界宽度为 `w_i`，`T_i` 为整个消元过程中实际生成并处理的精确符号片段总数，则成本写为：

```text
O(V+E) + sum(T_i * poly(w_i, log Q))
```

`T_i` 可以受图结构、系数、库存断点和余数约束影响，但禁止通过枚举 `0..Q` 产生 `Theta(Q)` 个状态。若宽度或符号片段数超过预算，则把该分量交回通用预算搜索并返回 best effort；不得改为识别图形后走特判。

## 宽度 3 示例：Fib 仅作为测试形状

考虑两条样板：

```text
R1: X(i-1) + X(i-2) -> Xi
R2: X(i-2) + X(i-3) -> Xi
```

若当前需要 `d` 个 `Xi`，其中 `u` 个走 `R1`，其余 `d-u` 个走 `R2`，则新需求为：

```text
X(i-1) += u
X(i-2) += d
X(i-3) += d-u
```

两条路线的净差向量是：

```text
(1, 0, -1)
```

共同的 `X(i-2)` 不构成取舍。处理完 `Xi` 后只需保存连续三个需求累加器，因此：

- 整条链仍可能有很多竞争节点；
- 整条链仍可能属于一个连通分量；
- 但有效 separator width 为 3；
- 单位系数版本的选择变量始终满足连续整数区间 `0 <= u <= d`，转移只含系数 `-1/0/1`，不会因请求数量产生逐份状态，不需要枚举 Pareto 点。

数量不同的变形仍然保持局部宽度，但可能需要保存 `gcd`、整除和余数约束。

这里没有任何 Fib 专用入口。`X(i-1)` 和 `X(i-3)` 会在后续层重新汇合，因此不会被错误标记为路线私有输入；通用未处理引用数会自然把它们保留在宽度为 3 的活动边界中。该示例的作用只是验证通用消元器没有按路径数递归展开。

## Missing 路线选择

### AE2 展示语义

AE2 可以在同一份 concrete plan 中列出多个缺失物品，但确认界面不会同时表达“路线 A 的缺口”和“路线 B 的缺口”这类互斥候选前沿。因此规划器必须先选定一套具体路线，再输出该路线传导完成后的 Missing；不能把互斥分支的缺口合并。

选择顺序为：

```text
1. 任意 Missing = 0 的完整可行计划，优先于所有不完整计划。
2. 没有可行计划时，比较路线在活跃共享竞争资源上的投影分数。
3. 路线私有原料只计算库存容量和可达性，不参与投影支配。
4. 选定路线后，冻结该选择并把其私有缺口继续传导到叶子。
5. 竞争资源投影仍不可比时，使用稳定样板顺序选择一份展示候选。
```

这里的投影分数是路线选择策略，不是对完整 Missing 向量的支配证明。未被选中的路线可以降低搜索优先级，但在没有证明时不能硬剪枝。

### `A/B/C` 示例

考虑：

```text
RA: A + alpha*C -> D
RB: B + beta*C  -> D
beta < alpha
```

`A`、`B` 是各自路线的私有输入，`C` 是两条路线真正争用的共享资源。

- `A`、`B` 的库存用于计算 `RA`、`RB` 各自能覆盖多少需求，以及选定路线后缺少什么。
- 路线选择只比较共享资源 `C`；`RB` 的单位 `C` 消耗更少，因此在没有完整可行计划时优先选择 `RB`。
- 选择 `RB` 后继续传导其输入。如果 `B` 无法合成且库存不足，最终展示 `missing B`。
- 不同时展示 `missing A` 与 `missing B`，因为它们来自两套互斥计划。
- 若 `RA` 能形成完整可行计划而 `RB` 仍缺 `B`，则直接选择可行的 `RA`；较低的 `C` 消耗不能压过可行性。

单一共享资源 `C` 的建议比较键为：

```text
(max(0, needC - availableC), needC, stableSequence)
```

先最小化 `C` 的实际缺口，再最小化总消耗，最后使用稳定样板顺序。这样即使两条路线都无法完成，也会稳定选择 `C` 压力更小的 `RB`，随后展示该路线的 `missing B`。

若同时存在多个共享竞争资源，则分别计算每种资源的缺口和消耗。分数能够逐项比较时选择不差且至少一项更好的路线；仍然不可比时不声称支配，交给稳定次序或局部预算搜索决定一份展示候选。

对于相同输出批量、私有输入彼此独立的路线，可以优先分配单位共享资源消耗较低的路线，并受各自私有库存容量约束。若批量、余数、副产物或多个共享资源造成耦合，则仍进入局部预算搜索，但展示语义不变。

### 复杂度

设：

- `N` 为实际比较的路线或完整候选数量；
- `r` 为活跃共享竞争资源数；
- `d` 为选定路线最终 Missing 的叶子种类数。

只维护一个展示候选时：

```text
路线投影比较      O(N*r)
选中路线传导      O(V_selected + E_selected)
结果向量额外空间  O(r+d)
```

单一共享资源 `C` 时路线选择退化为 `O(N)` 扫描，不需要产生随请求数量 `Q` 增长的 Pareto 前沿。完整 Missing 向量的支配检查只在已有两份完全可比候选、且需要证明性剪枝时执行，不进入默认展示路径。

## 预算化 Best-First 搜索

### 原则

- 启发式只改变优先级。
- 部分搜索状态即使看起来较差也不直接删除。
- 只有严格证明成立时才允许硬剪枝。
- 找到可行候选后立即优先于所有 Missing 非空的候选。
- 不可行候选只按活跃共享竞争资源的投影分数更新展示 incumbent。
- 完整 Missing 支配只有在可比条件充分时才参与证明性剪枝；它不是默认展示比较器。

### 优先级等级

```text
P0  乐观估计可能达到 Missing = 0
P1  乐观估计可能改善 incumbent 的共享资源投影分数
P2  与 incumbent 的投影分数相同或不可比
P3  当前估计的共享资源投影分数更差
```

队列排序建议：

```text
(priorityClass,
 estimatedSharedConflictScore,
 unresolvedConflictCount,
 routeDiscrepancyCount,
 stableSequence)
```

`P3` 仍保留在队列中。为避免启发式误判造成永久饥饿，可以每处理 8 到 16 个高优先级节点，强制处理一个低优先级节点。具体比例应由真实诊断数据决定，不写死为正确性条件。

### 可以硬剪枝的情况

- 完全相同的规划状态已经以不差的库存和需求访问过；
- 路线经过完整净资源、私有输入和全部副作用比较后被严格支配；
- 精确下界证明该状态的全部后代既不能可行，也不能改善展示策略规定的共享资源分数；
- 状态违反质量守恒、环启动种子或库存作用域约束。

容量估计、经验分数或局部 Missing 预测不得作为硬剪枝依据。

## `long` 数量与分配断点

路线分配变量不能遍历 `0..Q`。每个变量只生成有意义的断点候选：

- 某种库存刚好耗尽的位置；
- 某条路线刚好达到容量的位置；
- 线性松弛解的向上和向下取整；
- 区间端点；
- 批量、`gcd` 和余数约束附近的合法点；
- 启发式平衡点。

内部乘法和加法必须使用检查或饱和语义。数值不可表达不能伪装成普通原料 Missing。

## 预算退出与结果状态

建议明确区分：

```text
FEASIBLE
    Missing 为空；该结果支配所有非空 Missing，可以立即结束。

INFEASIBLE
    搜索已经证明不存在可行计划；返回按共享竞争资源策略选出的具体路线 Missing。

BEST_EFFORT
    预算或前沿上限耗尽；返回当前共享竞争资源分数最好的 concrete candidate，
    但尚未证明不存在可行计划或更优展示路线。

UNREPRESENTABLE
    请求或中间计数无法在支持的数值范围内精确表示。
```

`INFEASIBLE` 和 `BEST_EFFORT` 都必须保留完整、可回放、叶子级的 Missing。`BEST_EFFORT` 还要设置 `budgetExhausted=true`；它是“当前路线选择策略下的已知最好候选”，不是全局最优证明。

## 复杂度边界

设：

- `V`、`E` 为活动合成图规模；
- `B` 为允许扩展的搜索状态预算；
- `C_local` 为一次局部增量传播成本；
- `Q` 为请求数量。

目标复杂度：

```text
确定性传播与边界标记  O(V+E)
路线投影维护          O(N*r)
低宽度局部求解        sum(T_i * poly(w_i, log Q))
预算搜索              O(B*(C_local + log B))
数量算术              poly(log Q)，不得出现 O(Q) 循环
```

其中 `r` 是活跃共享竞争资源数，`w_i` 是局部分量在稳定逆拓扑序下测得的边界宽度，`T_i` 是实际保留的精确符号片段数。规范化完整 Missing 向量的支配检查只出现在可选的证明步骤中，不是默认候选维护成本。

一般高维合成分配仍然可能是 NP 难的；预算确保刻意构造的实例不会拖死计算线程。

## 建议实施阶段

### 阶段 1：候选语义与诊断

- 调整 `betterIncompletePlan`：可行计划优先；不可行计划按活跃共享竞争资源分数比较。
- 私有路线原料只计算库存容量，并在路线选定后传导 Missing。
- 禁止把互斥路线的 Missing 合并成一份候选。
- 投影分数相同或不可比时保持稳定样板顺序，不引入全局 Pareto 集。
- 增加候选数、共享资源分数、路线容量、选中路线和最终私有 Missing 诊断。
- 保持现有执行与计划转换逻辑不变。

### 阶段 2：搜索优先级

- 为搜索状态增加基于可行性和共享资源投影的 `P0..P3` 优先级。
- 保留低优先级状态，不基于启发式硬剪枝。
- 增加低优先级公平调度和前沿峰值诊断。

### 阶段 3：冲突核分析

- 收缩确定性下游。
- 计算 `L/U/S` 活跃资源分类。
- 构造冲突二部图并拆分独立分量。
- 输出 `activeResources`、`differenceRank`、`separatorWidth`。

### 阶段 4：通用宽度受限求解

- 使用现有稳定逆拓扑序和未处理引用数维护活动边界，不计算最优树宽。
- 对所有满足宽度和符号片段预算的分量使用同一个区间、仿射和同余状态求解器。
- 状态只在库存、容量、批量和余数等通用断点处分裂，不枚举合成份数。
- 通过精确状态合并和父指针回放输出一套具体路线分配。
- 对超过宽度或符号片段预算的分量继续使用当前有界搜索。
- 禁止按配方名、层级名、Fib 递推式或测试类选择求解路径。
- 诊断只报告通用字段，例如 `solverPath`、`separatorWidth`、`symbolicFragments` 和 `fallbackReason`，测试通过这些字段验证路径选择。

阶段 4 是“已解决多级竞争图”结论的必要组成，不再是针对某个存档决定是否实现的可选优化。运行时是否进入该路径只由通用图指标和预算决定。

## 验收用例

1. `Missing=0` 的可行计划始终优先于共享资源消耗更低但仍有 Missing 的计划。
2. 对 `RA: A + alpha*C -> D`、`RB: B + beta*C -> D` 且 `beta < alpha`，两条路线都不完整时选择 `RB`。
3. 选择 `RB` 后沿该分支传导并展示 `missing B`，不得同时加入互斥的 `missing A`。
4. `A`、`B` 库存变化必须影响各路线容量和可行性，但不能被当作共享资源 Pareto 维度。
5. 多条路线的共享资源分数相同或不可比时，结果由稳定路线顺序决定。
6. 条件不足时不得根据局部 Missing 声称支配或硬剪枝。
7. 只有完整叶子、库存作用域及全部副作用均可比时，严格支配才能触发证明性剪枝。
8. 低优先级路线不能被启发式静默删除，并能在公平调度后被访问。
9. 预算耗尽时返回选定路线的完整叶子 Missing，并标记 `BEST_EFFORT`。
10. 每一级都有两条路线的单位系数 Fib 深链必须通过通用低宽度路径完成，活动边界保持为 3。
11. 将 Fib 测试的全部物品名随机重命名、改变链长或嵌入其他确定性 DAG 后，必须进入相同求解路径并得到等价结果。
12. Fib 无库存、部分库存和 `long` 级请求量三组用例都不得按路径数或请求份数展开；无库存时 Missing 必须传导到叶子。
13. 数量系数变形使用同一个通用求解器覆盖区间、整除和余数边界，不增加变形专用分支。
14. 表面分支输入在下游重新汇合时必须标记为 `shared`，不得套用独立 A/B 的 Missing 投影规则。
15. 普通无竞争 DAG 只执行线性传播和边界标记，不创建局部符号状态。
16. 超过 30 种活跃资源或符号片段预算的刻意构造图在预算内退出。
17. 副产物、容器、模糊输入、一般可复用库存和配方环启动库存不能被错误支配剪枝；LT 闭环种子另由 AE2LT 规划器验证。
18. `UNREPRESENTABLE` 与普通原料不足必须保持不同结果语义。

## 展示顺序

本文解决的是“多个候选中选择哪一份 Missing”，不规定 Missing 行在 AE2 界面中的顺序。AE2 会重新构建并排序确认界面的条目，因此修改 Map 插入顺序不能可靠控制 UI；若以后需要改变显示顺序，应作为独立的客户端展示改动处理。
